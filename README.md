# Автоматизация бизнес-процессов
## Задание 3
Процесс "Обработка заявок службы технической поддержки"
Смоделируйте бизнес-процесс в любом редакторе используя BPMN нотацию:
1. 	Запрос регистрируется из различных источников Первой линией технической поддержки (примерные контекстные переменные: ФИО, Организация, E-mail, Телефон, Запрос).
2. 	Проблема решается:

a) 	силами Первой линией технической поддержки;

b) 	если первая линия не в состоянии ответить, то требуется консультация специалиста Второй линией технической поддержки, либо консультация Разработчиков.

3. 	После получения ответа Первая линия технической поддержки оповещает клиента (e-mail, телефон)

4. 	По результатам обратной связи с клиентом выясняется проблема решена или нет, если решена, то процесс заканчивается, иначе переходим к пункту 2.

## Решение
<img width="1057" height="568" alt="image" src="https://github.com/user-attachments/assets/8f2ea683-03b0-469e-a365-a48ec9a26233" />
На BPMN-диаграмме «Обработка заявок службы технической поддержки» процесс начинается с регистрации запроса первой линией поддержки. Затем проверяется, можно ли решить проблему на первом уровне. Если да — проблема решается, и процесс идёт к обратной связи с клиентом. Если нет — подключается консультация специалиста второй линии или разработчика, которые предлагают решение. После получения ответа первая линия оповещает клиента по email или телефону. Затем проверяется обратная связь от клиента: если проблема решена — процесс завершается, если нет — цикл повторяется снова (возврат к консультации специалиста или разработчика).
